# MK KRUPA Business Solutions

Website for MK KRUPA Business Solutions — brand development, marketplace assistance, product sourcing, business consulting and digital presence.

**Live site:** https://mk-krupa-business-s.netlify.app/

## About the Website

A single-page business website built with Next.js. It presents the company's six services, the industries and product categories it works with, the marketplaces it can help explore, how the team works, the team members, and an enquiry form that opens WhatsApp with the visitor's details pre-filled.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Edit `src/app/page.tsx` for content and `src/app/globals.css` for styles. The page auto-updates as you edit.

## Build

```bash
npm run build
npm run start
```

## Deployment

The site is deployed on Netlify and rebuilds automatically on every push to `main`.
